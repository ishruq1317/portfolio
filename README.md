## 🌟 Overview

This repository houses the modern, high-performance personal engineering portfolio for **Hasin Ishruq**. Designed with an **Obsidian Black glassmorphism aesthetic**, violet/cyan atmospheric gradients, and tactile physics-based mouse micro-interactions.

The site is built on the **Next.js 16 App Router (Turbopack)**, featuring strictly verified projects, accepted medical AI research, downloadable ATS-formatted CV, and a multi-channel interactive communication terminal.

---

## ⚡ Key Features & Motion Experience

- **🎯 Interactive Cursor Physics**: Trailing spring-damped follower ring (`InteractiveCursor.tsx`) with dynamic scale expansion and ambient halo lighting.
- **🧲 Magnetic Button Pull**: Fluid spring physics (`MagneticButton.tsx`) that pull primary call-to-actions smoothly toward the cursor on hover.
- **🧊 3D Dynamic Card Tilt & Lighting**: Real-time radial cursor lighting coupled with spring-smoothed 3D card tilt (`rotateX` / `rotateY`) on project cards.
- **📄 Authentic CV Integration**: Dedicated 1-click **Download CV (PDF)** and **View CV** buttons referencing the original verified document.
- **📬 Multi-Channel Contact Terminal**: Interactive contact form with live validation, animated submission state, Web Gmail one-click compose fallback, and clipboard copy actions.
- **📱 Responsive & Touch-Aware**: Custom cursor and physics automatically adapt or disable on touch screens via media queries for optimal mobile performance.

## 💻 Local Development & Setup

### Prerequisites
- Node.js `18.18+` or `20+`
- npm or pnpm or yarn

### 1. Clone the repository
```bash
git clone https://github.com/ishruq1317/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```
Open **[http://localhost:3000](http://localhost:3000)** in your browser to view the application with Hot Module Replacement (HMR).

### 4. Build for production
```bash
npm run build
npm run start
```
