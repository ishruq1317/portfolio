# Hasin Ishruq - Professional Portfolio

[![Live Demo](https://img.shields.io/badge/Live-Demo-brightgreen.svg)](https://portfolio-five-tau-p53ypcknoe.vercel.app/)
[![Next.js](https://img.shields.io/badge/Next.js-15-black?logo=next.js)](https://nextjs.org/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind-CSS-38B2AC?logo=tailwind-css)](https://tailwindcss.com/)

A premium, modern, and interactive developer portfolio showcasing full-stack projects, UI/UX designs, and technical skills. Built with Next.js, Tailwind CSS, and Framer Motion, featuring a custom glassmorphism dark theme.

## 🚀 Features

- **Premium Design:** Obsidian black theme with violet and fuchsia gradients.
- **Glassmorphism UI:** Translucent panels and frosted glass effects.
- **Interactive Elements:** Mouse-tracking spotlight effects on project cards.
- **Fully Responsive:** Optimized for mobile, tablet, and desktop viewing.
- **Performance Focused:** Built on Next.js App Router for optimal speed and SEO.

## 🛠️ Tech Stack

- **Framework:** [Next.js](https://nextjs.org/) (React)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)

## 💻 Getting Started locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ishruq1317/portfolio.git
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
5. Open [http://localhost:3000](http://localhost:3000) in your browser.
